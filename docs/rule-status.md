# 规则完成度（调试用）

> 对照 EP301 / EP302 voice 的可执行条目。规则正文见 `playbooks/rules.md`；本文件只记实现等级与实盘时要盯的问题。
> 跑法：`uv run python scripts/pipeline.py AMZN`（无档案 = 从头）。下断点见该脚本。

## 等级

| 标记 | 含义 |
| --- | --- |
| 完整 | 机器可判，与 voice 主条件对齐 |
| 近似 | `trust: review`，或算法简化（报告标 ⚠ 近似） |
| 人工 | `fact` / `checklist`；缺或过期 → 提问 |
| 提醒 | 盘后无法判，进 A，不影响结论 |
| 未做 | 明确推迟 |

无档案时结论是「先写想法理由」，写完 idea 后是「待回答 N 项」（V06 / V08 / V09 / V10b，以及未画的结构）。这是设计。

## 实盘先盯这些

1. **可执行 ≠ 今天该买。** 只表示计划没被否决、没过期；现价可以离 entry 很远。
2. **V04 缩量反弹没有下跌门控。** 上涨里的缩量回踩若当日收涨，上下文 V04 会否决整只股票，S01 / S02 可能被误杀。
3. **`ttl: 1` 每天重问：** V06、V10b、S08。V08 写止损日期（或 `false`），满 5 个交易日自动失效。
4. **V02 不读 `strength`，也不要求「逼近阻力」。** YAML 里的 strength 只存档。
5. **多计划时结论只显示第一条。** 同时只留一个 `active`。
6. **S08 建议买点没有止损**，V05 会否决该候选；要买必须把止损写进 `plans`。
7. **止跌形态只认锤子线与一级看涨吞没。** 启明星 / 倒锤子 / 孕线不会触发 S01 / S09。
